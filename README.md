# Vølven Python Debt Skill

Vølven sees the Python code that will hurt later.

This skill reviews Python for future cost: dynamic dictionaries, missing boundary validation, mutable globals, implicit schemas, async error drift, swallowed exceptions, and mock-heavy tests.

It does not replace Ruff, mypy, pyright, Black, isort, or normal test failures. It looks for the contracts those tools cannot see clearly enough.
